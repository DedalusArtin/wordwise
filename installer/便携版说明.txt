WordWise 0.41.0 便携版
=====================

这个包有两个版本，内容只差「有没有带上模型」：

  WordWise-0.41.0-portable.zip             不带模型（小，约 35 MB）
  WordWise-0.41.0-portable-with-models.zip 含模型（大，视模型而定，最大约 1.2 GB）

拿不准就选**不带模型**的那份：程序一样能用，只是第一次要用 AI 讲解时
要自己下一个模型（可选 400 MB 的 0.6B 小档，够用）。

运行
----
解压后双击 wordwise.exe 即可。
无需安装，不写注册表，不向系统目录拷贝文件。

请连同 vendor\llama 子目录一起拷贝，不要只拷 exe，否则「一键部署」
会退回联网下载引擎（镜像被限速，实测要十几分钟）。

系统要求
--------
- Windows 10 / 11（x64）
- WebView2 运行时。多数系统已自带。
  若启动后窗口空白或闪退，请到下面地址下载安装：
  https://developer.microsoft.com/microsoft-edge/webview2/
- 「AI 单词讲解」需要有一个大模型服务，三种办法任选其一：
    1) 用本程序自带的一键部署（左下角「AI 服务」按钮 → 启动）；
    2) 连接你已有的 LM Studio（在 LM Studio 里 Start Server 即可）；
    3) 用在线 API（设置 → AI 服务 → 服务来源，内置 DeepSeek / 通义千问 /
       Kimi / 智谱 GLM 等，填上 API Key 就能用）。
  三种都不配也能用其余功能。

数据存放（★ 便携版和安装版不一样，请留意）
------------------------------------------

**便携版**：所有数据都在**你自己这个文件夹里**，就在 exe 同级的 data\ 下面：

    <你解压的目录>\data\wordwise.db     词库、学习进度、错词本、讲解存档
    <你解压的目录>\data\models\         下载的模型（.gguf）

这是靠目录里的 portable.txt（一个空文件）实现的。
好处：整个文件夹拷到 U 盘就能带着走，换台电脑接着背，也不会往 C 盘写东西。
代价：**删掉这个文件夹 = 连词库和进度一起删掉。** 想留着就先备份，
      或者把它放到一个不会被随手清理的位置。

**安装版**：默认放在**软件安装目录**下的 data\，装到哪个盘就落哪个盘，
也不会写 C 盘。老版本升级上来的用户，数据仍在原位
（%APPDATA%\WordWise），不会被搬走。

两种情况都可以在「设置 → 数据与模型的存放位置」里看到真实路径和占用，
并且可以换到别的盘（可选把现有数据一起搬过去）。

想随身携带又不想用 portable.txt，也可以设环境变量指定数据目录，例如：
  set WORDWISE_DATA_DIR=D:\WordWiseData
  wordwise.exe
环境变量的优先级最高。

AI 服务怎么切换 / 怎么开关
--------------------------
窗口左下角有一个状态条，点它展开一个面板：

  - 没装引擎 → 按钮显示「去安装引擎」
  - 装了引擎但没下模型 → 显示「去下载模型」（模型 0.6B 约 400MB，1.7B 约 1.1GB）
  - 都齐了 → 显示「启动」；正在跑 → 显示「停止（释放内存）」
  - 正在用在线 API → 主按钮是「打开 AI 设置」，本机启停降为次要按钮

面板底部的「启动时自动拉起本地服务」开关打开后，下次开 WordWise 会自动起好，
不用每次手点。这个开关在「设置」页里也有一份，改哪边都一样。

想接在线 API：设置 → AI 服务 → 服务来源里选一家，点「申请 API Key」去官网拿一把
粘进去，再点「测试连接」。OpenAI / OpenRouter 这类境外服务要先在
「设置 → 网络与代理」里打开代理。

API Key 只保存在本机数据库里（跟学习数据同一个文件，明文未加密），
只会发给你自己填的那个服务，不会上传到别处。公用电脑上建议用完清空。

本机服务只监听 127.0.0.1，不对外网开放；退出 WordWise 会自动停止，
不会留在后台占内存，也不需要去任务管理器里手动结束进程。

模型太大想放到别的盘
----------------------
「设置 → 数据与模型的存放位置」里，模型文件那一行有「更换目录」。
可以只把模型挪到空间大的盘，不用动数据目录；改完立刻生效，不用重启。

网络行为
--------
默认直连，不使用系统代理；无代理环境下查词、在线搜索、词库下载均可正常使用。
需要代理时到「设置 → 网络与代理」里手动开启（默认关闭）。

卸载
----
直接删除整个目录即可。
按上面的说明，便携版的数据就在目录内的 data\，会一起被删掉 ——
删除前想留个底，先到「设置 → 数据库」点一下「备份」。

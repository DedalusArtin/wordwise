演示模式

刚装好还没开始背时，统计、复习计划、错词本、知识图谱都是空的。 打开这个开关会填一份示例数据，让你先看清这些页面长什么样。

示例数据不会写入数据库。开启后你仍然可以正常背单词， 真实成绩照样记录，只是这几个页面暂时显示示例。

AI 服务（本地模型 / 在线 API）

AI 讲解、AI 翻译兜底、断网时的查词都走这里配置的服务。两种来源任选： 本机模型（免费、离线、不联网、不需要 Key）或 在线 API（要填 Key，模型能力通常更强）。 两者协议相同，都是 OpenAI 兼容接口，程序不分优劣，只按下面的地址调用。

API Key 只保存在本机数据库里（跟学习数据存在一起，明文，没有加密）， 除了发给上面填的那个服务，不会上传到任何其它地方。公用电脑上建议用完清空。

本地大模型一键部署

没有 LM Studio 也可以用 AI 讲解：这里会下载一份 llama.cpp 引擎和 Qwen 模型， 在本机 127.0.0.1 上开一个 OpenAI 兼容服务，功能与 LM Studio 完全一致。 全程离线运行，不上传任何数据。 如果上面「服务来源」选了在线 API，这块就用不上，跳过即可。

显存 4GB 以下或纯 CPU 的机器建议选 0.6B（400MB，秒开）； 8GB 内存以上可以选 1.7B，讲解质量明显更好。

语言

界面语言决定按钮、菜单、提示用什么语言显示；讲解语言决定 AI 讲解与追问回复用什么语言书写。两者互相独立 —— 学日语时界面仍然 可以是简体中文。代码、命令、日志、文件路径等技术内容保持原文不翻译。

占位符说明：{LANG} 会替换成目标语言，{CONTENT} 会替换成 AI 的原始输出。技术内容会用 ⟦n⟧ 占位符保护， 翻译完成后自动还原，所以不会被误译。

网络与代理

默认直连，不使用代理。内置的在线词库（jsDelivr 镜像）、 中文释义（有道）、英英释义、在线搜索（必应 RSS）在国内都可以直接访问， 无需任何代理配置也能正常使用。即使系统里存在 HTTP_PROXY 环境变量或代理设置，也不会被自动采用 —— 只有打开下面的开关才会走代理。 需要访问被墙资源（如维基词典）时再打开即可。

词典与翻译源（可扩展小语种）

每个源通过 URL 模板 + 字段映射接入，新增语言或词典只需填写配置，无需改代码。 映射支持 a.b[0].c、a[*].b 这样的路径表达式。

数据库

所有数据都存在本机这一个 SQLite 文件里，关闭再打开不会丢。 备份用的是 VACUUM INTO：它导出的是一致性快照， 比直接复制 .db 文件可靠（直接复制可能拿到写入一半的状态）。

数据与模型的存放位置

语言与搜索

词条属于哪种语言由程序按书写系统自动判断：含假名判为日语、含谚文判为韩语、 纯汉字判为中文，拉丁字母词才沿用上面选的「查询语言」。 所以「选日语查中文词」不会再被当成日语词。

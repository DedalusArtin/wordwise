WordWise 是一款 Windows 桌面背单词软件：左边是干净的词条，右边是本地大模型逐字写出的讲解，答错的词自己钻进错词本、按遗忘曲线准时回到你眼前。前端纯原生 HTML/CSS/JS（无 node_modules），后端 Rust + Tauri 2，离线可用。

本版是自 **v0.35.0** 以来的第一个正式发布，包含 **v0.36 → v0.41** 的全部改动。

## 本版重点

### 1. 查词不再「明明连得上却显示查询失败」
原来的逻辑把 AI 服务当成了必要条件：AI 没开，就算好几个词典源都正常返回了结果，界面仍然整条命令报错、显示「查询失败」。现在**只要任意一个词典源返回结果就算查询成功**，AI 不可用只会在结果上方留一条提示条。同时修掉了朗读按钮点不动、句子朗读时会连带弹「查询失败」的问题。

### 2. 解析走三级阶梯，上游改版也不会瞎
匹配式（按配置的字段路径映射）→ 启发式（不看字段名，只看内容像不像释义）→ 纯文本（直接解析 HTML 页面）。词典站改字段名、换页面结构，都不至于让查询「连得上却查不出」。

### 3. AI 讲解自动存档，第二次点开不花算力
讲解写入 `explain_store` 表：可搜索、可一键并入词库变成可背的词条、可离线回看。同一词条第二次点开直接读本地。

### 4. 数据与模型的存放位置，看得见也搬得动
设置页新增「数据与模型的存放位置」面板：

- 一眼看清数据目录、数据库文件、模型目录、推理引擎各在哪、各占多少
- 列出**每块磁盘的剩余空间**，可一键把数据目录或模型目录换到别的盘
- 换目录时可选择**把现有文件一起搬过去**（数据库走 `VACUUM INTO` 一致性快照，源文件不删）
- 显示当前数据目录是怎么定下来的（环境变量 / 便携标记 / 指针文件 / 老数据 / 跟随程序 / 兜底）

数据目录解析顺序：`WORDWISE_DATA_DIR` → exe 同级 `portable.txt` → exe 同级 `location.txt` → 已有的 `%APPDATA%\WordWise\wordwise.db` → exe 同级 `data\` → `%APPDATA%\WordWise`。模型目录同理：`WORDWISE_MODELS_DIR` → `<数据目录>\models_dir.txt` → `<数据目录>\models`。改数据目录需重启（数据库已打开），改模型目录**立刻生效**。

### 5. 数据默认跟着软件走——装到 D 盘就不写 C 盘
新装环境下，数据默认落在 exe 同级的 `data\`，所以装在 D 盘就全在 D 盘。**老用户的数据原地不动**（已有的 `%APPDATA%\WordWise` 优先级更高，绝不会被搬走）。

### 6. 便携版分两种，安装程序默认避开 C 盘
- 便携包写入空 `portable.txt` 实现自包含，分**不含模型**（约 35 MB）和**含已下载模型**两种产物（打包脚本 `-ModelsDir` / `-SkipModelsZip` 参数控制）
- 安装程序默认目录改为**优先选非 C 盘**（先探测可写性，探不动才退回原默认）；卸载时对**新旧两处**数据目录都会询问是否一并删除

## 其余改动（v0.36 → v0.41）

- **独立翻译栏目**：左右分栏、实时翻译、复制 / 朗读 / 收藏 / 历史；在线引擎限频时自动降级本地大模型
- **句子翻译逐词可点**：译文里的每个单词拆成可点击链接，点一下直接查词，并支持类似浏览器的**返回上一页**（栈式历史）
- **互译方向选择器**：顶部「源语言 ⇄ 目标语言」一键互换，查词页与翻译页共用同一份方向
- **知识图谱（独立栏目）**：词与词的关系画成可缩放、可拖拽的力导向图。6 类关系各有配色，词库里写明的关系画**实线**、AI 推测的画**虚线**；点节点以它为中心展开，双击看释义或去查词
- **复习计划视图**：到期清单（逾期最久的排最前）+ 未来 14 天到期量可视化 + 记忆周期表图示
- **学习统计**：14 天答题柱状图 + 掌握度环形图 + 连续学习天数 + 正确率
- **错词本多维筛选**：按错误次数 / 错误率 / 掌握度筛选，5 种排序；一键导出 Markdown 或 CSV（可给 Anki 用）
- **背诵模式随学习库自适应**：背日语还是背英语，界面显示的释义语言与题型选项会自动跟着所选词库/教材切换
- **单词讲解结合本地词库**：讲解时先在词库里搜一遍，已收录的内容直接复用
- **AI 服务三来源一键切换**：程序自带本机一键部署 / 你已有的 LM Studio / 在线 API（DeepSeek、通义千问、Kimi、智谱 GLM、硅基流动、OpenRouter、OpenAI 预设，也可填任意 OpenAI 兼容地址）
- **本地大模型一键部署**：没有 LM Studio 也能用 AI 讲解，引擎随包装，模型三档可选（0.6B / 1.7B / 1.5B）；左下角状态条点开就是启停面板
- **演示模式**：设置里打开后统计 / 计划 / 错词本 / 图谱填充示例数据，**不写入数据库**，顶部有常驻横幅
- **数据库维护面板**：显示路径、体积、每张表行数；一键整理（VACUUM）、完整性检查、备份

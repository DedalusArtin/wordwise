## 本版重点

### 1. 背诵分词库 —— 不同词库的单词不再混在一起（用户反馈）

**症状**：词库下拉明明选了 A，「开始今日复习」还是把 B、C 库的到期词混进同一队；
底部「本轮已背 / 最近背过」把所有词平铺在一个列表里，分不清谁是哪本书的。

**根因**：两个入口口径不一致 —— 「开始背诵」按书出题，「开始今日复习」的签名里
**根本没有 bookId**，后端 `due_states(lang)` 只按语言取全库；已背列表平铺渲染，
而 `WordRow` 不带词库归属字段，前端想分也没数据。

**修法（三层同口径）**：

- **队列**：`cmd_start_review_session` 新增 `bookId` → `due_states_in_book`
  （`EXISTS` 子查询；空书 id 退回全库 =「全部词库」历史行为不变）；
- **统计**：`cmd_stats` 支持 `bookId` —— 四张卡与「开始今日复习（N 词）」的 N
  只数所选书的词，按钮数字与队列不再当众打架；切换下拉立即刷新；
- **列表分容器**：新增 `cmd_word_book_refs` 批量反查词的词库归属；已背列表按词库
  渲染成多个容器（组头 = 词库名 + 词数）。多属词只进一组不重复计数
  （所选库优先 → 书名字序 → 「未入词库」兜底）；同步首渲 + 后台补查原地重渲，
  列表绝不因反查空一帧。

### 2. 查词条有道式专栏 —— 每个词格式一致、两处入口排版一致（用户反馈）

**症状**：同一个词在查词页与详情卡长得不一样；craftsman 有 [释义][变形] 两个标签、
fault 可能只有 [释义]；义项「n. 故障 / 断层… v. 弄错」词性悬空、全无编号。

**根因**：① 详情卡是**四份手抄渲染**（renderDefs/renderInfl/renderEx/renderRel），
与查词页 `renderEntry` 各画各的；② 栏目是**条件生成**的（有数据才有这个块），
栏目集合跟着数据走；③ 词典源会把领域标签塞进音标字段 —— fault 的英/美音标
实际存的是 `"[地质]"` 和裸数字 `"41"`。

**修法**：

- **固定专栏序列 `entryBlocks`（全项目唯一实现）**：释义 → 例句 → 变形 → 记忆法 → 相关词。
  核心三栏（释义/例句/变形）**永远在位**，无数据显示占位并点名「AI 讲解」补齐；
  记忆法/相关词有数据才追加（有道也不给没数据的词开空栏目）。
  查词页与详情卡调同一份 HTML —— 两处排版逐字节一致；
- **有道式释义**：词性组头只标一次、组内义项编号 1. 2. 3.（按 pos 变化自动切组）；
- **例句独立专栏**：全量去重、中英对照、每句带朗读；
- **音标前后端双清洗**：`isUsableIpa` / `clean_phonetic_value` 拒收领域标签与裸数字，
  按语言分流（日语假名、中文拼音不受影响）；联网解析与词表导入两个入库口都过闸，
  污染不再进库。音标全被清洗时音标行退回纯发音按钮，不给用户看乱码；
- 「对应词汇」对照卡保持紧凑：无数据整栏收起，不摆占位框。

### 3. 讲解正确性三道闸 ——「讲解了有道上根本没有的词」（用户反馈）

**现场取证**（本机库）：`grievance` 词条的变形栏有一个变体 `grievaunce`（古体拼写），
点进去后 —— ① 有道 suggest 对这个不存在的词联想返回了 **grievance 的整套中文释义**，
而源配置的词头映射到 `query`（原样回显你的输入），**没人校验词头和释义不是同一个词**；
② AI 讲解的 prompt 写着「已知词典释义（供参考，**可补充纠正**）」—— 这四个字纵容
模型推翻词典：词典明明写着 *Obsolete form of grievance*，模型却"纠正"成 grieve 的
n/v/adj 三词性，词源、搭配、例句整段编造；③ 你上有道一查，当然「根本没有这个词」。

**三道闸**：

| 闸 | 改动 |
| --- | --- |
| 数据源 | suggest 词头映射改为 `data.entries[0].entry`（真实联想词）；`pick_entry` 出口加**词头错配过滤**，词头≠查询词的整源丢弃 —— grievaunce 只剩 *Obsolete form of grievance* 这句诚实释义 |
| AI prompt | 词典释义改为**「唯一事实来源」**：词性词义不得添加、不得矛盾；词源没把握**不得编造**；词典标注为变体（form of X）时**第一句必须说明这层关系**并围绕 X 讲；无释义时第一段先判断「是不是标准词」 |
| 修复入口 | 已存的错误讲解点「**重新讲解**」按新 prompt 覆盖；旧的错配词条缓存点「**强制刷新**」重建 |

### 4. 变形栏按词性给全并标明（用户要求「动名形容时态单复数变形要表明」）

- AI 生成词典数据的 prompt 明确按词性给全：动词 → 过去式/过去分词/现在分词/
  第三人称单数，名词（可数）→ 复数，形容词 → 比较级/最高级，label 必须中文；
- 前端 `inflMeta` 把中英 label 归一（`past tense`→过去式、`plural`→复数、
  `comparative`→比较级…），**每条挂词性徽标**：`v. 过去式`、`n. 复数`、
  `adj. 比较级` —— 查词页与详情卡共用同一套渲染。
